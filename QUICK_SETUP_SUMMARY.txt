WHAT TO DO NOW (Super Simple!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You need TWO THINGS from Google:
  1. Client ID
  2. Client Secret

TO GET THEM:

1. Open: https://console.cloud.google.com
   (Sign in if asked)

2. Create a new project called "RadAI"

3. Search for "Google+ API" and enable it

4. Go to Credentials → Create OAuth Client ID
   (It will ask you to set up consent screen - do it with your email)

5. Set application type to "Web application"

6. In "Redirect URLs" add this exact URL:
   https://vqycjjkfqzmiueebmkkk.supabase.co/auth/v1/callback

7. Click CREATE

8. A popup shows Client ID and Client Secret
   → Copy both

THEN:

9. Come back to the Supabase page (screenshot above)

10. Paste Client ID in the empty field

11. Paste Client Secret in the other empty field

12. Click "Save changes" button (blue)

DONE! ✅

Google Sign-In now works!
