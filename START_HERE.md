## 📞 Something Wrong?

### Common Issues

**Voice not working?**
- Use Chrome, Firefox, Safari, or Edge (not IE)
- Allow microphone permission when prompted
- Type instead if voice fails (manual mode works)

**Report not generating?**
- Check you have text in the textarea
- Verify internet is connected
- Try simpler dictation first

**PDF not downloading?**
- Check browser popup blocker
- Try different browser
- Ensure JavaScript is enabled

### Getting Help

1. Check `DOCTOR_TESTING_GUIDE.md` FAQ section
2. Look at error message (it tells you what's wrong)
3. Document issue with reproduction steps
4. Report systematically
