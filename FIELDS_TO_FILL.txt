THE TWO FIELDS YOU NEED TO FILL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Field #1: Google Client ID
─────────────────────────
Where to get it:
  1. Go to: https://console.cloud.google.com
  2. Create project "RadAI"
  3. Enable Google+ API
  4. Credentials → Create OAuth Client ID
  5. Application type: Web application
  6. Add redirect URL:
     https://vqycjjkfqzmiueebmkkk.supabase.co/auth/v1/callback
  7. Click CREATE
  8. In the popup, you'll see "Client ID" - copy that

What it looks like:
  123456789-abcdefghijklmnop.apps.googleusercontent.com

Where to paste it:
  In Supabase, the "Google Client ID" field


Field #2: Google OAuth Client Secret
────────────────────────────────────
Where to get it:
  Same popup from Google as Client ID above!
  Click "Show" if hidden

What it looks like:
  GOCSPX-abcdefghijklmnopqrstuvwx

Where to paste it:
  In Supabase, the "Google OAuth Client Secret" field

STEP-BY-STEP PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ✅ You're in Supabase (screenshot shows this)

2. ❌ Google fields are empty (the two fields with red outline above)

3. Go to Google Cloud Console: https://console.cloud.google.com

4. Create OAuth credentials (following steps in GOOGLE_OAUTH_FLOW.txt)

5. Get Client ID and Client Secret from the popup

6. Come back to this Supabase page

7. Paste Client ID in "Google Client ID" field

8. Paste Client Secret in "Google OAuth Client Secret" field

9. Click "Save changes" button

10. ✅ DONE! Google Sign-In is now working
