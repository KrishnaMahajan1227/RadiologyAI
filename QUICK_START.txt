🎯 YOUR FIRST REPORT IN 6 MINUTES

  1️⃣  CREATE ACCOUNT (1 min)
      → Click "Get Started" on landing page
      → Sign up with email/password
      → You're in!

  2️⃣  OPEN NEW REPORT (0 min)
      → Click "New Report" in sidebar

  3️⃣  SELECT TEMPLATE (1 min)
      → Scan Type: "Ultrasound Abdomen"
      → Template: "Ultrasound Abdomen - Kidney Stone"
      → See section preview appear

  4️⃣  DICTATE FINDINGS (1 min)
      → Click red Mic button
      → Say: "Left kidney multiple stones 8mm hydronephrosis"
      → Watch text appear in real-time
      → Click Stop when done

  5️⃣  GENERATE REPORT (1 min)
      → Click "Fill Template & Generate" button
      → AI fills all sections automatically
      → Wait 3-5 seconds

  6️⃣  DOWNLOAD OR SAVE (1 min)
      → Click "PDF" to download
      → Click "Save" to store in account
      → Done! Professional report generated

🎙️ VOICE DICTATION TIPS

  SPEAK LIKE THIS ✓
  "Left kidney multiple stones, largest 8 millimeters, with moderate
   hydronephrosis. Right kidney unremarkable. No free fluid."

  NOT THIS ✗
  "Kidney looks okay, has stones maybe"

  BEST PRACTICES
  • Use proper medical terminology
  • Include measurements
  • Describe both sides/structures
  • Speak at normal pace
  • Clear audio = better results

🛠️ TROUBLESHOOTING

  VOICE NOT WORKING?
  • Click "Get Started" if browser prompts for microphone
  • Use Chrome, Firefox, Safari, or Edge (not IE)
  • Type instead if voice fails (fully manual mode works)
  • Reload page if microphone button doesn't appear

  REPORT NOT GENERATING?
  • Check you have text in the dictation box
  • Verify internet connection is stable
  • Try simpler dictation first (shorter findings)
  • Check error message shown in alert box

  PDF NOT DOWNLOADING?
  • Check browser popup blocker settings
  • Try different browser
  • Check Downloads folder
  • Ensure JavaScript is enabled
